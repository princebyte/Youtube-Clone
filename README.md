A responsive YouTube clone built using HTML5 and CSS3.

## Features

- YouTube-style navigation bar
- Sidebar with menu options
- Search bar
- Video cards and thumbnails
- Subscription section
- Responsive layout
- Clean and user-friendly UI

## Technologies Used

- HTML5
- CSS3
- CSS Flexbox
- CSS Grid
